# 按需交接，不上传整个工作目录

每人把接收方需要的产物整理到自己的目录：`handoffs/A/<版本>/`、`handoffs/B/<实验编号>/`、`handoffs/C/<实验编号>/`。这里只交付必要结果，个人运行目录和环境保持本地。

每次交接至少包含一份 `README.md` 或 `manifest.json`，写明：

1. 交付人、用途、接收人、数据版本与代码commit。
2. 每个文件的相对路径、SHA-256、格式和样本量（适用时）。
3. 接收方可复制的相对路径命令、概率方向、评估口径及已知限制。
4. 接收方要执行的验收检查，以及哪些文件只是调试产物。

A 的正式训练数据直接放 `data/processed/<版本>/`，这里引用路径即可，不重复拷贝。B/C优先交调参集预测、参数和指标摘要；最终需要协作加载的训练模型放 `handoffs/shared_models/<版本>/`，并使用LFS。

不要上传解释器、Conda/venv目录、依赖缓存、IDE设置、访问令牌、本机路径配置、完整控制台日志、无用中间checkpoint或个人实验全目录。
