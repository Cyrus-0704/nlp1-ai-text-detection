## 证据和解释边界

1. 两个seed的512均提高同seed的全体F1和临时S。s42的全体F1提升1.420pp、S提升1.627pp；s43分别提升5.314pp和4.129pp。两个seed只能作初步复验，不能据此估计可靠的训练seed分布。两项512的S仍相差2.802pp，训练稳定性尚不足以忽略。
2. s43长度提升主要减少human误报（1334→561），代价是machine漏报85→188；全体错误1419→749。其全体F1与C基本接近，短文本更好；C/B各自单独正确569/567条，共错180条，互补性清楚。
3. 固定融合总错误534→440，比旧融合净少94条；全体F1+0.704pp，临时S+0.597pp。dev组配对bootstrap（1000次、seed20261016）S差的条件95%区间为[+0.230,+0.969]pp；短文本F1差区间跨零。相对C单模型，融合S+2.566pp，区间[+2.098,+3.107]pp。区间以已拟合模型及同dev上的选择为条件，不能消除选择偏差，不是独立泛化或seed置信区间，未作多重比较校正。
4. 融合沿用C原先网格声明的.7/.3，本轮没有新权重/阈值搜索，也没有拟合校准器。单B s43短文本F1=.956943高于该融合.953381，不能声称融合每个分项均胜出。
5. s43在1000/2000步的全体F1=.945235/.945575，S=.948830/.948986，S差条件区间[-.515,+.572]pp。与此同时log loss .154007→.169904、Brier .040248→.041883，human高置信错误(p≥.99)100→141。不支持仅因训练损失下降就继续追加预算；保留预定2000终点，1000只作诊断。
6. s42加长后的log loss仍变差；s43表现更好不代表此问题普遍解决。切片只作同dev描述；domain/generator并非未见域/未见生成器实验，不据此作OOD归因结论。
