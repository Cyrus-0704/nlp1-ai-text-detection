## 输入与交付标准

输入：A六字段train/dev和统一评估命令；B同一dev的 `sample_id,p_machine`。

交付：

- 基线代码、模型与向量器的保存/加载逻辑；必要模型用LFS。
- `handoffs/C/<实验编号>/`：dev预测、参数、数据版本/哈希、代码commit、A脚本指标、简短错误分析。
