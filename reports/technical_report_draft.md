> **草稿状态：**供队内协作修改，不是最终提交版。全文不填写队伍、学校或个人身份。`[待确认]` 项须由相应负责人补充。当前短文本口径与融合结果均为内部 dev 探索结果，不得写成官方成绩。

## 摘要

本工作面向初赛的人类撰写文本与机器生成文本二分类任务。我们先以字符级 TF-IDF 与逻辑回归建立轻量基线，再与 XLM-R 主模型比较，并在固定内部开发集上探索概率融合。internal-v2 的 15,086 条 dev 样本上，基线全体宏 F1 为 0.9468；按临时空白分词规则统计的短文本宏 F1 为 0.9185。与 seed 43 的 2,000 步主模型按 0.7/0.3 概率加权后，dev 综合分为 0.9580。由于短文本定义仍待官方确认，且融合权重在同一 dev 集上选择，该融合结果仅用于开发分析，尚未冻结，也不是官方验证成绩。

## 1. 任务与方案概览

初赛任务是对输入文本判断来源类别：人类撰写（human，标签 0）或机器生成（machine，标签 1），并输出机器类别概率 `p_machine`。本文讨论来源检测，不判断文本事实真伪；复赛涉及的生成器归因和人机混写片段定位不属于本文当前实验范围。

方案包括两条路线：

1. 轻量基线：字符 n-gram TF-IDF 特征加类别均衡的逻辑回归。
2. 主模型：基于 XLM-R 的文本分类器，由主模型负责人训练。

在基线和主模型的同一内部 dev 预测上，评估单模型表现、错误互补性和简单概率融合。全流程使用固定数据划分，不自行重新切分数据。

## 2. 数据与评测

### 2.1 数据清洗和固定划分

原始数据共读取 95,889 条记录。按 A 提供的 internal-v2 预处理流程，展开实际文本字段和评审列表；仅在文本确实以相应提示词开头时剥离提示词。过滤少于 20 个字符的文本（human 7,101 条、machine 93 条），按来源标识和规范化正文去重（human 72,136 条、machine 14,074 条），并对机器文本按生成器与正文去重。每条最终输出正文都参与分组；共享来源或重复正文的样本被分配到同一集合，以避免跨集合泄漏。

internal-v2 划分采用 seed 42 的 group-based 约 80/10/10 划分。本文开发实验只使用 train 和 dev：

| 集合 | 样本数 | Human | Machine |
| --- | ---: | ---: | ---: |
| Train | 119,842 | 43,922 | 75,920 |
| Dev | 15,086 | 5,495 | 9,591 |

Train SHA-256：`5a5dca9db706e0faadc5c89cbcadc77dc585ce302f5e73b11b82213f40ab7ff6`。  
Dev SHA-256：`1d80e7b6045e0914f224dcbc3afe5f56569f5bd995f742607389c26316476600`。

两份文件的字节数和 SHA-256 均与 A 的 internal-v2 manifest 一致。内部 test 未参与本文模型训练、调参、评估或融合选择；官方验证集未用于文本探查、统计或调参。

### 2.2 指标和评估协议

使用全体样本二分类宏平均 F1，以及短文本子集宏平均 F1。综合分定义为：

$$
S = 0.7 \times \mathrm{MacroF1}_{all} + 0.3 \times \mathrm{MacroF1}_{short}
$$

本轮开发使用阈值 0.5，即 `p_machine >= 0.5` 判为 machine。短文本暂按空白分词数量小于 100 计数，dev 中共有 1,841 条短文本。**该计词规则不是已确认的官方多语言计词规则**；官方计词、阈值和最终 CSV 格式由 A 核实后，应统一重算相关结果。本文所有标为“临时”的指标不得作为官方成绩引用。

## 3. 方法

### 3.1 字符级 TF-IDF 与逻辑回归基线

基线使用字符级 TF-IDF，n-gram 范围为 2–5，`min_df=2`，最多保留 300,000 个特征；分类器为 `C=1`、`max_iter=1000`、`liblinear` 求解器的逻辑回归，并使用 `class_weight="balanced"` 缓解类别不平衡。随机种子为 42。

TF-IDF 词表、IDF 和分类器参数仅在 train 上拟合；dev 只用于预测与开发评估。模型输入只有正文，不使用 sample_id、group_id、generator 或 domain 作为特征。训练耗时约 530.6 秒。输出概率列 `p_machine` 表示 machine（标签 1）的概率。

### 3.2 XLM-R 主模型

主模型使用 `FacebookAI/xlm-roberta-base`，固定 revision 为 `e73636d4f797dec63c3081bb6ed5c7b0bb3f2089`。本轮共享的开发对照包括 CE500、CE2000 seed 42 和 CE2000 seed 43。共同配置为最大长度 256、batch size 1、梯度累积 16、学习率 `2e-5`、AdamW、weight decay 0.01、FP16、梯度检查点及恒定学习率。

每个 2,000 步模型抽取约 32,048 条训练样本，约占 train 行数的 26.7%，因此不是完整训练遍历或最终冻结模型。主模型环境和训练细节由负责人核实补充：**[待 B 确认最终主模型设置、训练覆盖、运行硬件及模型包状态]**。

### 3.3 概率融合

对 C 与 B 的机器类别概率进行加权平均：

$$
p_{blend} = w_C p_C + (1-w_C)p_B
$$

在 dev 上以 0.1 为步长测试 `w_C=0.1...0.9`，再以 0.5 阈值计算分类指标。该搜索仅用于比较是否存在互补信号，不构成独立验证；最终权重须在官方评测口径确认、主模型候选稳定后由团队决定。

## 4. 实验结果

### 4.1 单模型比较

| 模型 | 全体宏 F1 | 短文本宏 F1* | 临时综合分 S* |
| --- | ---: | ---: | ---: |
| 字符 TF-IDF + 逻辑回归（C） | 0.9468 | 0.9185 | 0.9383 |
| XLM-R CE500 | 0.8820 | 0.8766 | 0.8804 |
| XLM-R CE2000 seed 42 | 0.9024 | 0.9101 | 0.9047 |
| XLM-R CE2000 seed 43 | 0.8924 | 0.9433 | 0.9077 |

\* 短文本为暂定的空白分词数 `<100`，阈值为 0.5。以上均为同一 internal-v2 dev 的内部开发结果，不是官方成绩；B 的 2,000 步模型亦未完成全量训练。

### 4.2 融合比较

| 融合候选 | C/B 权重 | 全体宏 F1 | 短文本宏 F1* | 临时综合分 S* |
| --- | ---: | ---: | ---: | ---: |
| C + B CE500 | 0.7/0.3 | 0.9577 | 0.9416 | 0.9529 |
| C + B CE2000 seed 42 | 0.7/0.3 | 0.9608 | 0.9352 | 0.9532 |
| C + B CE2000 seed 43 | 0.7/0.3 | 0.9614 | 0.9499 | 0.9580 |

三个 B 候选的粗网格最优点均为 C/B=0.7/0.3。以 seed 43 融合为例，按 group_id 进行 500 次配对 bootstrap 后，综合分相对 C 基线的条件 95% 区间为 `[0.0148, 0.0257]`。该区间以当前模型和在同一 dev 上选择的融合权重为条件，不能消除选择偏差，也不覆盖训练 seed 不确定性，因此不应解释为独立泛化置信区间。

### 4.3 错误与切片分析

C 基线在全体 dev 上有 319 条 human 被误判为 machine、428 条 machine 被误判为 human。暂定短文本子集中，1,841 条样本有 81 条 human 误报和 38 条 machine 漏报；human 召回率为 0.8451，低于 machine 召回率 0.9712。

按领域切片的描述性结果中，`RuATD_2022`（1,202 条）宏 F1 为 0.8749，`PeerRead/iclr_2017/`（1,266 条）为 0.9009。生成器切片只包含 machine 单类，宏 F1 不适用；可报告漏报率，例如 `dolly-v2` 为 34/216（15.7%），`gpt-3.5-turbo` 为 130/2,660（4.9%），`text-davinci-003` 为 105/1,640（6.4%）。这些切片在当前 dev 上只作描述，不代表未见生成器泛化能力。

模型错误并不完全重叠。按“C 单独正确/B 单独正确”统计，CE500 为 1,326/494，CE2000 seed 42 为 1,116/557，CE2000 seed 43 为 1,247/575。该现象支持继续检查融合，但不能单凭 dev 上的改善决定最终采用。

## 6. 局限与讨论

1. 当前结果依赖 internal-v2 dev，不能替代官方验证集或隐藏测试集结果；未评测内部 test，也未声称对新生成器的泛化性能。
2. 短文本使用临时空白切词规则，官方多语言计词口径尚未确认，相关短文本指标与融合选择需要按统一口径重新计算。
3. 融合权重在同一 dev 上选择并报告，具有选择偏差。需在方案冻结后按团队流程进行内部 test 的一次正式评估，再决定最终方案。
4. B 的 2,000 步模型仅覆盖约 26.7% 的训练行；主模型训练覆盖和最终候选尚未冻结。
5. 生成器切片只有单一真实类别，无法用双类宏 F1 衡量；领域和生成器小切片样本量有限，结论仅供错误定位。
6. A 的预处理脚本曾在控制台打印每个集合的示例文本，其中包括 internal test 示例。本文未用 test 训练、调参或评估；后续应由 A 关闭 test 示例打印，并按团队规则避免浏览或分析 test 内容。

## 7. 结论与待办

在已固定的 internal-v2 dev 上，字符 TF-IDF 基线提供了有竞争力的轻量对照，且与 XLM-R 预测存在一定错误互补。粗网格概率融合在该 dev 上提高了临时综合分，但短文本规则尚未由官方确认、权重也在同一 dev 上选择，故当前只保留为探索结论，不宣布最终模型或融合方案。
